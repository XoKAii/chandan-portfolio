Project 01 • Ongoing Learning

Programming & DSA Practice

1. Objective

Build rigorous, foundational computational competence by solving algorithmic challenges, understanding memory mechanics, and implementing core data structures from scratch in C and C++.

2. Technologies

C C++ Data Structures Algorithms VS Code

3. Work Completed

  • Implemented searching routines (Linear Search, Binary Search) with asymptotic analysis.
  • Practised classic sorting algorithms (Bubble, Selection, Insertion Sort) and evaluated time complexity.
  • Constructed fundamental dynamic data structures including singly linked lists, stacks, and queues.
  • Explored recursive problem-solving and basic binary tree traversal concepts.

4. Challenges

Understanding pointer arithmetic, managing manual memory allocation/deallocation in C, and avoiding boundary edge-case faults in dynamic structures.

5. Learning Outcomes

Developed structured debugging discipline, a deep appreciation for algorithmic efficiency ($O(n)$ vs $O(n^2)$), and confidence with compiled programming languages.

Project 02 • Learning

Python & Data Analytics

1. Objective

Explore Python programming paradigms and the core mechanics of exploratory data analysis, dataset inspection, and identifying patterns within tabular data.

2. Technologies

Python Data Analytics Pandas NumPy Basics Jupyter Notebooks

3. Work Completed

  • Studied Python object-oriented constructs, functions, exception handling, and modules.
